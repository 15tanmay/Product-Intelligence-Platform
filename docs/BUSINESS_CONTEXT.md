# Business Documentation

## Primary Objective
Answer the core question: **"Why are first-time customers not becoming repeat customers?"**

## Metrics Monitored
1. **First-Time vs Repeat Ratio**: Evaluates baseline retention.
2. **Delivery Delta Impact**: Correlation between late deliveries and failure to repurchase.
3. **RFM Segmentation**: Recency, Frequency, Monetary value to identify "at-risk" vs "loyal" cohorts.
4. **Cohort Analysis**: Tracks retention decay month-over-month.

## Business Assumptions
- Churn is implicit (no subscription). A customer is considered churned if no repeat purchase occurs within 180 days.
- Logistics (delivery time) is a primary driver of e-commerce satisfaction.
