# Product Intelligence Platform

## Customer Behaviour & Product Decision Support System

This platform is a production-grade internal analytics tool designed to answer one critical business question:
**"Why are first-time customers not becoming repeat customers?"**

## Features
- **Executive Dashboard**: High-level KPIs and automated insights.
- **Retention Analytics**: Analysis of delivery impact and customer churn.
- **RFM Segmentation**: Recency, Frequency, Monetary value customer clustering.
- **Cohort Analysis**: Month-over-month retention tracking.

## Architecture
Built using **Clean Architecture** principles:
- **Core**: Business Rules
- **Use Cases**: Retention, Segmentation, Revenue analytics.
- **Adapters**: SQLite Data Access, Plotly Visualization.
- **Presentation**: Streamlit Dashboard.
